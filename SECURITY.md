# Security Policy

## Supported Versions

Security fixes are provided for the latest published version of FORMULA ASCENT.

| Version | Supported |
| ------- | --------- |
| 0.0.3.x | Yes |
| < 0.0.3 | No |

This policy may change as the project evolves.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub Issues, discussions, or other public channels.

Use GitHub's **Private vulnerability reporting** feature on this repository's **Security** tab, if it is enabled. This allows you to send a report privately to the repository maintainer.

When submitting a report, include as much of the following information as possible:

- A clear description of the vulnerability and its potential impact.
- The affected version, page, feature, or component.
- Steps to reproduce the issue.
- A proof of concept or screenshots, if they help explain the issue.
- Any suggested mitigation, if known.

The maintainer will review the report and make a reasonable effort to acknowledge it within 7 days. This is a target, not a guaranteed response time. Further updates will depend on the complexity and severity of the issue.

Please allow the maintainer time to investigate and prepare a fix before sharing details publicly. If a report is accepted, the issue will be addressed where reasonably possible and the reporter will be informed about the outcome. If it is not considered a security vulnerability, the reporter will be informed where possible.

Thank you for helping keep FORMULA ASCENT and its players safe.
